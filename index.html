วิธีการใช้งาน
วิธีที่ 1 — Data Attribute
ใส่แค่ attribute เดียว lib init ให้อัตโนมัติ
แนะนำ 
// HTML เท่านั้น ไม่ต้องเขียน JS เลย
<input type="text" data-thaidatepicker placeholder="วว/ดด/ปปปป">
Value Attribute — ดึงค่าจากฐานข้อมูล
ใส่ค่าใน value ได้เลย lib แปลงและแสดงเป็น พ.ศ. อัตโนมัติ
value 
<!-- YYYY-MM-DD ค.ศ. (MySQL) → แปลงเป็น พ.ศ. อัตโนมัติ -->
<input data-thaidatepicker
       value="<?php echo $row['date']; ?>">

<!-- DD/MM/YYYY พ.ศ. → ใช้ได้เลย -->
<input data-thaidatepicker
       value="15/08/2567">
วิธีที่ 2 — JavaScript Instance
เก็บ reference ไว้เรียกใช้ method ภายหลัง + onChange callback
JS
รอเลือกวันที่...
const picker = new ThaiDatePicker(el, {
  format: 'DD/MM/YYYY',
  onChange: function(val) {
    val.day        // → 5
    val.month      // → 3
    val.yearBE     // → 2567
    val.yearCE     // → 2024
    val.formatted  // → "05/03/2567"
    val.longFormat // → "5 มีนาคม พ.ศ. 2567"
  }
});
Custom Format
ปรับรูปแบบวันที่ผ่าน data-format
data-format 
<input data-thaidatepicker data-format="D/M/YYYY">
Instance & Static Methods
getValue() / setValue() / clear()
อ่านค่า ตั้งค่า และล้างค่า
const val = picker.getValue();
// null ถ้ายังไม่เลือก หรือ { day, month, yearBE, yearCE, formatted, longFormat }

picker.setValue(1, 1, 2567);  // 1 มกราคม พ.ศ. 2567
picker.clear();
open() / close() / toggle()
ควบคุม popup calendar ด้วย code
picker.open();  picker.close();  picker.toggle();
setReadonly(bool)
ล็อก/ปลดล็อก input
Readonly mode
เปิดเพื่อล็อก input ไม่ให้กดได้
picker.setReadonly(true);   // ล็อก — input เป็นสีเทา
picker.setReadonly(false);  // ปลดล็อก
new ThaiDatePicker(el, { readonly: true }); // ตั้งแต่แรก
ThaiDatePicker.setValueFromISO()
ตั้งค่าจาก YYYY-MM-DD ค.ศ. แปลงปีให้อัตโนมัติ รับ element หรือ selector
static 
ThaiDatePicker.setValueFromISO('#m4', '2024-08-15');
// ค่าว่าง / 0000-00-00 → clear() อัตโนมัติ
ThaiDatePicker.setValueFromISO('#m4', '');
ThaiDatePicker.getInstances()
ดูทุก instance ในหน้า หรือหา instance จาก element
static 
const list = ThaiDatePicker.getInstances();
list.length; // จำนวน picker ในหน้า
const inst = list.find(i => i.input.id === 'm1');
Submit Format — เลือกค่าที่ส่งไป Server
ไม่กำหนด submitFormat (default)
ส่งค่าตาม format ที่แสดง เช่น 05/03/2567 (พ.ศ.)
default 
<input data-thaidatepicker name="date_default">
// submit → "05/03/2567"
submitFormat: 'BE'
ส่งเป็น YYYY-MM-DD พ.ศ. เช่น 2567-03-05
BE
เลือกวันที่เพื่อดูค่าที่จะส่ง...
new ThaiDatePicker(el, { submitFormat: 'BE' });
// submit → "2567-03-05"

// หรือ data attribute
<input data-thaidatepicker data-submit-format="BE">
submitFormat: 'CE'
ส่งเป็น YYYY-MM-DD ค.ศ. เหมาะกับ MySQL
CE / MySQL
เลือกวันที่เพื่อดูค่าที่จะส่ง...
new ThaiDatePicker(el, { submitFormat: 'CE' });
// submit → "2024-03-05" (ค.ศ.)
// lib สร้าง hidden input ให้อัตโนมัติ ย้าย name ไปให้
ระบบเลือกเวลา (Scrollable Time Picker)
โหมดเลือกเวลาเท่านั้น (Time Only)

New Mode 
<input data-thaidatepicker data-only-time="true">
เลือกวันที่ร่วมกับเวลา (Scroll UI)
UI แบบเลื่อนเลือกที่ใช้งานง่ายกว่าเดิม
<input data-thaidatepicker data-enable-time="true">
เรียกใช้งานผ่าน JavaScript
รองรับการดึงค่าเวลาผ่าน getValue()
const picker = new ThaiDatePicker(el, {
  onlyTime: true,
  onChange: function(val) {
    console.log(val.hour, val.minute);
  }
});

Installation & Usage Guide
1. ติดตั้งไฟล์ (Setup)
คัดลองไฟล์ CSS และ JS ไปไว้ในโปรเจกต์
<!-- CSS -->
<link rel="stylesheet" href="thaidatepicker.css">

<!-- JavaScript -->
<script src="thaidatepicker.js"></script>
2. การใช้งานแบบอัตโนมัติ (HTML Auto-init)
เพียงใส่ attribute data-thaidatepicker
<input type="text" data-thaidatepicker>

<!-- ปรับแต่งผ่าน Data Attributes -->
<input type="text" 
       data-thaidatepicker 
       data-lang="en" 
       data-era="ce" 
       data-enable-time="true">
3. การใช้งานผ่าน JavaScript (Manual Init)
ควบคุมได้ละเอียดขึ้นผ่าน Options
const picker = new ThaiDatePicker(document.getElementById('my-input'), {
    lang: 'th',             // 'th' | 'en'
    era: 'be',              // 'be' (พ.ศ.) | 'ce' (ค.ศ.)
    format: 'DD/MM/YYYY',   // Format วันที่
    enableTime: true,       // เปิดเลือกเวลา
    showTodayButton: true,  // แสดงปุ่มวันนี้
    showClearButton: true,  // แสดงปุ่มล้างค่า
    onChange: (val) => {
        console.log(val);   // { formatted, yearBE, yearCE, hour, minute, ... }
    }
});
4. การเชื่อมต่อช่วงวันที่ (Range Picker)
เชื่อม 2 Input เข้าด้วยกัน
<input id="start" data-thaidatepicker data-linked-to="#end">
<input id="end" data-thaidatepicker>
