วิธีที่ 1 — Data Attribute

แนะนำ
// HTML เท่านั้น ไม่ต้องเขียน JS เลย <input type="text" data-thaidatepicker placeholder="วว/ดด/ปปปป">
วิธีที่ 2 — JavaScript Instance
เก็บ reference ไว้เรียกใช้ method ภายหลัง + onChange callback
JS
รอเลือกวันที่...
const picker = new ThaiDatePicker(el, { format: 'DD/MM/YYYY', onChange: function(val) { val.day // → 5 val.month // → 3 val.yearBE // → 2567 val.yearCE // → 2024 val.formatted // → "05/03/2567" val.longFormat // → "5 มีนาคม พ.ศ. 2567" } });
Custom Format
ปรับรูปแบบวันที่ผ่าน data-format
data-format
<input data-thaidatepicker data-format="D/M/YYYY">
Instance & Static Methods
getValue() / setValue() / clear()
อ่านค่า ตั้งค่า และล้างค่า
const val = picker.getValue(); // null ถ้ายังไม่เลือก หรือ { day, month, yearBE, yearCE, formatted, longFormat } picker.setValue(1, 1, 2567); // 1 มกราคม พ.ศ. 2567 picker.clear();
open() / close() / toggle()
ควบคุม popup calendar ด้วย code
picker.open(); picker.close(); picker.toggle();
setReadonly(bool)
ล็อก/ปลดล็อก input
Readonly mode
เปิดเพื่อล็อก input ไม่ให้กดได้
picker.setReadonly(true); // ล็อก — input เป็นสีเทา picker.setReadonly(false); // ปลดล็อก new ThaiDatePicker(el, { readonly: true }); // ตั้งแต่แรก
ThaiDatePicker.setValueFromISO()
ตั้งค่าจาก YYYY-MM-DD ค.ศ. แปลงปีให้อัตโนมัติ รับ element หรือ selector
static
ThaiDatePicker.setValueFromISO('#m4', '2024-08-15'); // ค่าว่าง / 0000-00-00 → clear() อัตโนมัติ ThaiDatePicker.setValueFromISO('#m4', '');
ThaiDatePicker.getInstances()
ดูทุก instance ในหน้า หรือหา instance จาก element
static
const list = ThaiDatePicker.getInstances(); list.length; // จำนวน picker ในหน้า const inst = list.find(i => i.input.id === 'm1');
Submit Format — เลือกค่าที่ส่งไป Server
ไม่กำหนด submitFormat (default)
ส่งค่าตาม format ที่แสดง เช่น 05/03/2567 (พ.ศ.)
default
<input data-thaidatepicker name="date_default"> // submit → "05/03/2567"
submitFormat: 'BE'
ส่งเป็น YYYY-MM-DD พ.ศ. เช่น 2567-03-05
BE
เลือกวันที่เพื่อดูค่าที่จะส่ง...
new ThaiDatePicker(el, { submitFormat: 'BE' }); // submit → "2567-03-05" // หรือ data attribute <input data-thaidatepicker data-submit-format="BE">
submitFormat: 'CE'
ส่งเป็น YYYY-MM-DD ค.ศ. เหมาะกับ MySQL
CE / MySQL
เลือกวันที่เพื่อดูค่าที่จะส่ง...
new ThaiDatePicker(el, { submitFormat: 'CE' }); // submit → "2024-03-05" (ค.ศ.) // lib สร้าง hidden input ให้อัตโนมัติ ย้าย name ไปให้
